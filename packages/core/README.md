# packages/core/

Shared domain types for CrossCheck (TypeScript, `src/types.ts`).
Sprint 2 scope only: `IngestionResult`, `ParsedLandingPage`,
`ExtractedLink`, `EntityGuess`, `EntityMatchSignal`, `PageType`,
`ExtractedClaim`, `LandingPageAnalysis` — see
`docs/design/SPRINT_2_IMPLEMENTATION_PLAN.md` "Data Models".

Types for Source Resolution, Comparison, and Reporting are documented in
`docs/design/WEBSITE_QUALITY_DESIGN.md`'s "Data Structures Summary" but not
implemented here yet — added when the sprint that builds them starts, not
speculatively.
